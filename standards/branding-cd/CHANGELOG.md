One block per version of this module. A rule that is withdrawn is listed as a tombstone; its ID is never reused.

## v0.1 · 2026-09-05

Skeleton. Ten rule IDs, the asset layout and the token file exist and are wired into the mechanism; every value is a `[FILL: ...]` placeholder and the module status is `draft`, so nothing here can be reported as passed.

To make it real: transfer the CD manual into `rules.md` and `assets/tokens.json`, drop the licensed asset files into `assets/`, record their licences in `assets/README.md`, set `status: active` and `version: 1.0`, then `/speckit-idea-standards --bind` on each active idea.
